# monitor.USP_ExecutionPlanAnalysis

## Zweck und Einsatz

Analysiert genau ein direkt übergebenes oder gezielt beschafftes Showplan-XML. Der direkte @PlanXml-Pfad ist eigenständig nutzbar.

## Voraussetzungen und Rechte

Der Aufruf braucht EXECUTE auf [monitor].[USP_ExecutionPlanAnalysis] im vorgesehenen Datenbankkontext. Die Procedure kann Plan-Cache- und Query-Statistik-DMVs sowie optionale aktuelle Planfunktionen lesen. Diese Server-Sicht ist versions-/rechteabhängig; ein Cacheeintrag ist keine Ausführungsgarantie.

**@PlanXml:** @PlanXml xml. Default ist NULL. Optionales bereits vorhandenes Plan-XML als SQL-Typ xml oder in diesen Typ konvertierbarer Text. Ein gesetzter Wert wählt IMPORTED exklusiv gegenüber PlanHandle, SessionIds und Query-Store-Paar. NULL wählt diese Quelle nicht; dann muss genau eine andere Quelle gesetzt sein. Leeres XML zählt als gesetzte Quelle, garantiert aber keinen auswertbaren Showplan. Wohlgeformte XML-Typkonvertierung ersetzt keine Showplan-Schemaprüfung. Die enthaltene Query wird niemals ausgeführt.

**@PlanHandle:** @PlanHandle varbinary(64). Default ist NULL. Binärwert als T-SQL-Hexliteral 0x… oder varbinary-Variable; der Typ fasst höchstens 64 Bytes. Kürzere Werte einschließlich 0x werden nicht separat abgewiesen und zählen als gesetzte Quelle. NULL lässt die Handlequelle ungesetzt. Ein unbekannter Handle liefert keinen Plan; die Beschaffung folgt @PlanQuelle. Es wird weder kompiliert noch SQL ausgeführt. Genau eine der Quellen PlanXml, PlanHandle, SessionIds oder vollständiges Query-Store-Paar darf gesetzt sein.

**@SessionIds:** @SessionIds nvarchar(max). Default ist NULL. Optionale Liste genau einer Session-ID im Bereich 1 bis 32767. Der Parser akzeptiert Pipe, Komma und Semikolon als Trennzeichen sowie Leerraum um Elemente; eine leere gesamte Eingabe wird wie nicht gesetzt behandelt. Ungültige Elemente, mehrere IDs oder Werte außerhalb des Bereichs ergeben INVALID_PARAMETER. NULL/Leerwert lässt die Quelle ungesetzt.

**@RequestId:** @RequestId int. Default ist NULL. Optionale ganze Request-ID ohne zusätzliche Bereichsprüfung. Sie filtert die aktuelle Planbeschaffung der gewählten Session. NULL ist bei höchstens einem verfügbaren Request zulässig; mehrere aktive Requests ohne RequestId erzeugen den intern abgefangenen Fehler 51031 und ERROR_HANDLED. Ohne Session wählt dieser Wert keine eigene Quelle; er wird aber als Parameter-Evidenzkontext an die Engine weitergegeben.

**@QueryStoreDatabaseName:** @QueryStoreDatabaseName sysname. Default ist NULL. Ein einzelner Datenbankname als sysname, keine Liste oder Qualifierkette. Der Name wird als Datenwert mit QUOTENAME in den Datenbankkontext eingesetzt; äußere Klammern werden nicht als Bezeichnermaskierung entfernt. NULL wählt diese Quellhälfte nicht, leerer Text wird nicht in NULL normalisiert und kann bei der Beschaffung scheitern. QueryStorePlanId muss gemeinsam gesetzt sein, andere Planquellen sind ausgeschlossen. Quellenfehler werden abgefangen; Verfügbarkeit und Berechtigungen bleiben erforderlich.

**@QueryStorePlanId:** @QueryStorePlanId bigint. Default ist NULL. Ganze bigint-Plan-ID im Query Store der angegebenen Datenbank. NULL lässt diese Quellhälfte ungesetzt; QueryStoreDatabaseName muss gemeinsam gesetzt sein. Es besteht keine zusätzliche positive Bereichsprüfung. Nicht vorhandene IDs liefern ohne verfügbares XML UNAVAILABLE_OBJECT; Berechtigungsfehler werden gesondert ausgewiesen.

**@PlanQuelle:** @PlanQuelle varchar(24). Default ist 'AUTO'. Geschlossene Auswahl AUTO, COMPILE, LAST_ACTUAL; NULL wird wie AUTO behandelt; Trim/Großschreibung werden normalisiert, leer/unbekannt ergibt INVALID_PARAMETER. Nur für @PlanHandle: AUTO versucht zuerst sys.dm_exec_query_plan_stats mit dem letzten tatsächlichen Plan und fällt auf COMPILE zurück; COMPILE liest den kompilierten Plan mit sys.dm_exec_query_plan und kompiliert oder führt keine Abfrage aus; LAST_ACTUAL fordert den letzten tatsächlichen Plan an. Die effektive Planquelle kann IMPORTED, COMPILE, LAST_ACTUAL, CURRENT_ACTUAL oder QUERY_STORE sein.

**@StatementId:** @StatementId int. Default ist NULL. Optionale ganze Statement-ID ohne zusätzliche Bereichsvalidierung. NULL deaktiviert den Filter. Der Wert wird für die Statistik-Evidenz und AUTO-Profilzuordnung benutzt und filtert danach fertige Statements samt abhängigen Ergebniszeilen. Er begrenzt nicht die vorgelagerte vollständige XML-Analyse der Engine. Eine nicht vorhandene ID kann leere Statement-/Detailmengen ergeben.

**@StatementQueryHash:** @StatementQueryHash binary(8). Default ist NULL. Optionaler 8-Byte-Queryhash als binary(8), vorzugsweise Hexliteral 0x mit genau 16 Hexziffern. NULL deaktiviert den Filter. SQL-Typkonvertierungen können kürzere oder längere Werte anpassen; es gibt keine zusätzliche Inhaltsprüfung. Der Hash beeinflusst AUTO-Profilzuordnungen und filtert nach der Analyse fertige Statements und abhängige Details, nicht die Beschaffung der Planquelle.

**@StatementQueryPlanHash:** @StatementQueryPlanHash binary(8). Default ist NULL. Optionaler 8-Byte-Planhash als binary(8), vorzugsweise Hexliteral 0x mit genau 16 Hexziffern. NULL deaktiviert den Filter. SQL-Typkonvertierungen können Werte auffüllen oder kürzen; eine eigene Inhaltsprüfung fehlt. Er filtert nach der Analyse fertige Statements und abhängige Details und beschafft keinen Plan.

**@EvidenzJson:** @EvidenzJson nvarchar(max). Default ist NULL. Optionales Execution-Evidence-JSON als Ausgangshülle; kein SQL-Befehl. NULL bedeutet keine importierte Evidenz, leerer Text ist ungültig. Erkannte Wurzelabschnitte sind statisticsIo, statisticsTime, statistics, objectReferences und predicateHistogramMappings; statistics enthält planUsage, currentSnapshot, histogramSummaries und histogramSteps. Die nachfolgenden JSON-Eingabeformen nennen alle projizierten Felder und SQL-Zieltypen. Die Hülle wird vor der Analyse immer durch USP_CreateExecutionEvidenceJson mit StrictValidation=1, RawTextHandling=HASH_ONLY und intern RAW-Identifikatoren normalisiert; die abschließende Analyseprojektion verwendet den angeforderten Identifikatormodus. Mit dem beschafften Plan stammen PlanUsage und Objektbezüge aus diesem XML; aktuelle importierte Arrays werden bei CURRENT_SERVER nicht geladen. Syntaxfehler werden im Helfer als INVALID_EVIDENCE_JSON abgefangen und markieren die Analyse partiell; die Analyse kann mit noch vorhandenen Daten fortfahren. Unbekannte Eigenschaften werden nicht als beliebige Zusatzdaten exportiert. Dies ist ein Eingabeformat des Evidence-Generators und kein erneut einzulesendes schemaVersion-3-Analyseergebnis.

**@StatisticsIoText:** @StatisticsIoText nvarchar(max). Default ist NULL. Optionaler, bereits erfasster STATISTICS IO-Meldungstext. NULL/Auslassen oder Leertext liefert keine daraus geparsten Zeilen. Der Text wird mit @StatisticsLanguage geparst; Teil- und Nicht-Erkennung bleibt als ParseStatus sichtbar. 053 setzt keine StatementOrdinal-Zuordnung und hat keinen öffentlichen Rohtextmodus; exportierter Rohtext wird nicht durch diesen Parameter gesteuert.

**@StatisticsTimeText:** @StatisticsTimeText nvarchar(max). Default ist NULL. Optionaler, bereits erfasster STATISTICS TIME-Meldungstext. NULL/Auslassen oder Leertext liefert keine daraus geparsten Zeilen. Der Parser kennzeichnet teilweise oder unbekannte Formate statt fehlende Messwerte zu erfinden; er erkennt englische/deutsche Textteile. 053 setzt keine StatementOrdinal-Zuordnung und hat keinen öffentlichen Rohtextmodus.

**@StatisticsLanguage:** @StatisticsLanguage varchar(16). Default ist 'AUTO'. AUTO erkennt unterstützte Meldungsteile automatisch; EN bezeichnet Englisch und DE Deutsch. Der IO-Parser normalisiert Groß-/Kleinschreibung und fällt bei NULL, leerem oder unbekanntem Code auf AUTO zurück. Der TIME-Parser verwendet die Kennung nicht und erkennt seine englischen/deutschen Textteile selbst. Es entsteht kein INVALID_PARAMETER für einen unbekannten Sprachcode.

**@StatistikEvidenzModus:** @StatistikEvidenzModus varchar(16). Default ist 'PLAN_ONLY'. Zulässig sind NONE, PLAN_ONLY, USED, RELEVANT und OBJECT_ALL. NONE überspringt die Extraktion von Statistiknutzung aus dem übergebenen Plan. PLAN_ONLY extrahiert diese Compile-Evidenz ohne aktuelle Katalogabfrage. USED ergänzt aktuelle Metadaten der im Plan verwendeten Statistiken. RELEVANT ergänzt diese um Statistiken, deren führende Spalte einer im Plan referenzierten Predicate-Spalte entspricht. OBJECT_ALL ergänzt alle Statistiken der referenzierten Planobjekte. Aktuelle Ergänzungen benötigen aufgelöstes Plan-XML und CURRENT_SERVER; die beiden breiten Modi benötigen High-Impact-Bestätigung. Importierte Statistikarrays werden durch NONE nicht pauschal entfernt. NULL fällt auf PLAN_ONLY zurück; äußere Leerzeichen und Groß-/Kleinschreibung werden normalisiert. Leerer oder unbekannter Code ist INVALID_PARAMETER. RELEVANT und OBJECT_ALL lösen das äußere High-Impact-Gate schon bei Anforderung aus, auch mit EVIDENCE_ONLY.

**@HistogrammModus:** @HistogrammModus varchar(16). Default ist 'NONE'. geschlossene Auswahl NONE, SUMMARY, STEPS. NULL wird wie NONE behandelt; Trim und Großschreibung normalisieren Werte, unbekannte Werte sind INVALID_PARAMETER. NONE erhebt keine Histogramme; SUMMARY liefert Zusammenfassungen; STEPS liefert Histogrammschritte. SUMMARY und STEPS benötigen @MetadatenQuellenmodus=CURRENT_SERVER sowie @StatistikEvidenzModus USED, RELEVANT oder OBJECT_ALL; sonst INVALID_PARAMETER.

**@MetadatenQuellenmodus:** @MetadatenQuellenmodus varchar(16). Default ist 'EVIDENCE_ONLY'. Zulässig sind EVIDENCE_ONLY und CURRENT_SERVER. EVIDENCE_ONLY verarbeitet übergebene Plan-/JSON-/Meldungsevidenz ohne aktuelle Statistikabfragen. CURRENT_SERVER ruft die aktuelle Erhebung nur mit aufgelöstem Plan-XML und Statistikmodus USED, RELEVANT oder OBJECT_ALL auf; importierte currentSnapshot-, Histogramm- und Predicate-Mapping-Arrays werden dann nicht geladen, auch wenn keine Erhebung stattfindet. CURRENT_SERVER verlangt unabhängig von einer tatsächlichen Erhebung @QuellumgebungBestaetigt=1; 0 und NULL führen zu SOURCE_ENVIRONMENT_CONFIRMATION_REQUIRED. Die Bestätigung des Aufrufers ist kein Herkunftsnachweis und keine Berechtigung. NULL als Quellenmodus bedeutet EVIDENCE_ONLY; Trim und Großschreibung werden normalisiert. Leerer oder unbekannter Code ist INVALID_PARAMETER.

**@QuellumgebungBestaetigt:** @QuellumgebungBestaetigt bit. Default ist 0. Eingabeform ist ein einzelner SQL-bit-Wert oder eine bit-Variable; leerer Text ist keine vorgesehene Eingabeform. SQL Server konvertiert Argumente vor Procedure-Eintritt zu bit; numerische Nichtnullwerte ergeben bit 1, daher ausdrücklich 0 oder 1 übergeben. Bei CURRENT_SERVER bestätigen 0 und NULL die Quelle nicht und führen unabhängig von einer tatsächlichen Erhebung zu SOURCE_ENVIRONMENT_CONFIRMATION_REQUIRED. 1 ist die Bestätigung des Aufrufers, dass CURRENT_SERVER der tatsächlichen Quelle entspricht; sie ist kein Herkunftsnachweis und erteilt keine Berechtigung. Ohne CURRENT_SERVER hat der Schalter keine Erhebungswirkung.

**@MitPredicateHistogramMap:** @MitPredicateHistogramMap bit. Default ist 1. Eingabeform ist ein einzelner SQL-bit-Wert oder eine bit-Variable; leerer Text ist keine vorgesehene Eingabeform. SQL Server konvertiert Argumente vor Procedure-Eintritt zu bit; numerische Nichtnullwerte ergeben bit 1, daher ausdrücklich 0 oder 1 übergeben. 0 überspringt die Predicate-/Histogrammzuordnung im Collector; 1 aktiviert sie bei tatsächlich aufgerufenem Collector. **@AnalyseTiefe:** @AnalyseTiefe varchar(16). Default ist 'STANDARD'. Geschlossene Auswahl SUMMARY, STANDARD, FULL. NULL wird wie STANDARD behandelt; Trim/Großschreibung normalisieren, leer/unbekannt ergibt INVALID_PARAMETER. 053 übergibt die normalisierte Tiefe nicht an 051; FULL fordert zusätzlich die High-Impact-Klasse SHOWPLAN_XML_DEEP an. **@WorkloadProfil:** @WorkloadProfil varchar(32). Default ist 'AUTO'. AUTO oder Profilcode; NULL wird wie AUTO behandelt, Trim/Großschreibung normalisieren. Weitere lokal konfigurierte Profile bilden eine offene Menge. Unbekannte oder deaktivierte Codes lösen keinen INVALID_PARAMETER aus, sondern fallen auf BALANCED zurück.

**@Regelsatz:** @Regelsatz varchar(32). Default ist 'DEFAULT'. Ausschließlich DEFAULT ist unterstützt. NULL wird wie DEFAULT behandelt; Trim/Großschreibung normalisieren. Andere Codes ergeben INVALID_PARAMETER; ein konfigurierbarer zusätzlicher Regelsatz ist nicht implementiert.

**@MinSchweregrad:** @MinSchweregrad varchar(16). Default ist 'INFO'. Geschlossene Auswahl INFO, LOW, MEDIUM, HIGH, CRITICAL; NULL wird wie INFO behandelt. Trim/Großschreibung normalisieren; leer/unbekannt ist INVALID_PARAMETER. Legt die untere Findings-Schweregradgrenze fest, nicht die Analysequelle.

**@MitThreadRuntime:** @MitThreadRuntime bit. Default ist 0. Eingabeform ist ein einzelner SQL-bit-Wert oder eine bit-Variable; leerer Text ist keine vorgesehene Eingabeform. **@MitSqlText:** @MitSqlText bit. Default ist 0. Geschlossene Auswahl 0 oder 1; NULL und Werte außerhalb dieser Auswahl ergeben INVALID_PARAMETER. 0 setzt StatementText vor der Ausgabe auf NULL. 1 behält Statementtext nur nach @SensitiveDataConfirmed=1 bei; 0 oder NULL als Bestätigung führt zu SENSITIVE_DATA_CONFIRMATION_REQUIRED und lässt StatementText in JSON- und TABLE-Ausgaben NULL. **@EvidenzDatenschutzModus:** @EvidenzDatenschutzModus varchar(24). Default ist 'DERIVED_ONLY'. Geschlossene Auswahl DERIVED_ONLY, TOKENIZED, STRUCTURE_ONLY, RAW.
